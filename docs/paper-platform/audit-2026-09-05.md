# Paper Workspace reliability audit — 2026-09-05

Scope: the standalone `daehwa00/paper-workspace` repository, including the browser application, collaboration server, compiler, backup service, password gate, Codex bridge, runtime staging, public export tooling, and deployment configuration. The separate LNet research repository was preserved without changes.

## Corrections

- Tie managed-source writeback to each Yjs document instance. Flush pending edits when the last connection destroys the document, and reattach observers after reconnecting.
- Keep runtime-managed shared sources authoritative during browser startup until server reconciliation. Preserve intentionally empty shared documents without reseeding stale disk content.
- Keep undo/redo with each file's CodeMirror state. Map external edits through the smallest changed range, and keep editor fallback adapters consistent.
- Detect edits made during both the pre-restore backup and the snapshot download before applying a restore.
- Preserve all manuscript files in `paper/drafts/`; directory membership no longer triggers automatic deletion.
- Report unavailable required sources explicitly while allowing empty and unfinished text files to be edited.
- Align compressed backup retention with the database and serialize export/pruning operations.
- Invalidate follower-tab PDFs after image revisions, and export/import the compile-extension sets used by those paths.
- Compare Unicode passwords and session signatures as bytes.
- Preserve the existing comment rendering and reconnect-status improvements; prevent sidebar controls from overlapping the resize handle.
- Make the legacy SyncTeX integration fixture use the actual compiler temporary-directory contract without weakening source-path validation.
- Verify generated client bundles in CI and isolate browser regression rooms. Correct the documented conflict-preservation direction.

## Production rollout follow-up

A second review before deployment found and corrected additional persistence edge cases:

- Restore deleted or malformed locked Yjs files from disk.
- Restore source, comments, and tasks atomically, updating the editor before autosave observers run.
- Seed shared comments/tasks only during initial migration; a cleared map in an established room stays empty.
- Tolerate missing text fields in older comment data without interrupting rendering.
- Bound HTTP shutdown to one second before draining runtime requests and flushing persistence. Give collaboration containers a 60-second graceful shutdown window.

Follow-up validation: **177 Python tests, 32 server tests, and 100 browser workflows passed**. All service images were rebuilt using the existing production configuration. Runtime storage formats are unchanged.
