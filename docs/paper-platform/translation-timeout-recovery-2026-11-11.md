# Translation timeout recovery · 2026-11-11

최근 응답 번역이 대기열에서 약 0.1초 후 시작했지만 모델 호출 120초 제한으로 반복 실패했다. 서비스 자원은 정상이었고, 21개 구간 중 18개 캐시는 유효했다. 미처리 일반 문장은 547/300/132자로 원문 크기 초과 문제는 아니었다. 같은 모델의 짧은 진단과 실제 번역 경로 진단은 성공했고, 후속 실제 요청도 완료되어 일시적 모델 응답 지연이 확인됐다. 제공자 내부 지연 원인까지 확정한 것은 아니다.

## 처리

- translate_block 입력 1–1600자는 한 호출 60초, 긴 블록과 다른 분석 작업은 기존 120초를 유지한다. 모델·추론 수준은 변경하지 않는다.
- 명시적 model_timeout만 해당 구간에서 한 번 자동 재시도한다. 검증 실패의 기존 1회 교정과 별도이며, 교정 때문에 timeout 재시도 예산이 초기화되지 않는다.
- 성공 구간과 기존 캐시를 다시 호출하지 않는다. 캐시 키·원문 분할·용어집·수식/코드 검증은 유지한다.
- 취소가 우선하며 인증·사용량 제한·busy·일반 네트워크 오류를 무조건 재시도하지 않는다. 두 번째 timeout은 기존 오류 코드로 보고한다.
- 응답 번역 화면에 지연 구간 재시도 상태와 완료 구간 수를 표시한다. 작업 자체를 새로 생성하지 않는다.

번역 단위 검사 49개 및 진행 상태 브라우저 검사 1개가 통과했다. 새 이미지 안의 실제 import/시간 정책을 확인했다. 실제 모델에서 고의로 시간 초과를 유도하지 않았으며 재시도·취소·캐시 보존은 제어된 실패로 검사했다. 검증 중 최신 실제 번역은 약 18.5초에 완료됐다(변경에 따른 속도 비교 주장은 아님).
