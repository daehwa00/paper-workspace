# 한국어 번역의 수식 어순 검증 수정 · 2026-11-10

영문 답변을 한국어로 번역할 때 31개 문단 중 8개를 처리한 뒤 반복해서 실패했다. 9번째 문단의 실제 모델 응답을 별도로 받아 원인을 재현했다. 영어의 `P satisfying X`가 한국어에서 `X를 만족하는 P`로 바뀌었으며, 수식의 내용과 등장 횟수는 모두 동일했다. 검증기는 보호된 수식의 배열 순서까지 비교해 이 정상 번역을 거부했다.

## 수정

- 인라인 수식·코드는 정확한 원문 값과 등장 횟수로 비교한다. 한국어 문법에 따른 인라인 표현의 이동은 허용한다.
- 독립 수식과 코드 블록은 원문 순서도 유지한다. 수식·코드의 변경, 누락, 추가·중복은 계속 거부한다.
- 수식·코드 보존 실패를 구체적인 검증 항목으로 분류한다. 그 밖의 문단 번역 검증 실패도 `기타 결과 검증 오류` 대신 번역 오류로 분류한다.
- 모델·추론 설정과 번역 요청·결과 계약, 캐시 키 버전은 유지한다.

## 검증 및 복구

번역·분석·서비스 검사 164개가 통과했다. 실제로 받은 동일 모델 출력이 수정 전에는 거절되고 수정 후에는 통과함을 확인했다.

실패했던 답변 전체를 `rebuttal-translation-light`로 재실행해 31개 문단 모두 완료했다. 기존 캐시 8개와 진단에서 검증한 문단 1개를 재사용했고 나머지 모델 호출은 22회였다. 원문 재조립이 입력과 일치했다. 검증된 새 캐시 23개를 해당 프로젝트에 추가했으며, 기존 캐시 값은 덮어쓰지 않았다. 캐시 외 모든 테이블의 행 수와 내용 해시가 추가 전후 동일했다.

운영 컨테이너에서 동일 답변을 다시 처리했을 때 모델 호출 없이 캐시로 31/31 문단을 완료했다. 최신 재시도 요청의 원문도 검증한 원문과 일치했다. 사용자는 화면의 `다시 번역`으로 결과를 적용할 수 있다. 현재 한국어 본문을 직접 덮어쓰지 않았다.
