# 새로고침 후 리뷰·답변 언어 복원 · 2026-11-11

리뷰의 원어·한국어와 답변의 English·한국어 선택을 논문별로 따로 기억한다. 같은 브라우저에서 새로고침하거나 다시 열 때 첫 렌더부터 저장된 선택을 사용한다. 두 항목을 한국어로 선택했다면 둘 다 한국어로 복원하며, 서로 다른 언어 조합도 그대로 유지한다.

기존 `PaperPreferenceStorage`의 안전한 브라우저 저장 래퍼를 사용한다. 키는 `paper-rebuttal-review-language:{slug}`, `paper-rebuttal-answer-language:{slug}`이고 값은 언어 식별자뿐이다. 본문을 추가로 저장하거나 공동 작업자의 언어 선택을 바꾸지 않는다. 잘못된 저장값은 원어·영어 기본값으로 처리하며 저장소가 막혀도 화면 전환은 동작한다.

한국어 초기화는 공동 편집 준비가 끝날 때까지 기다려 정상 초기화 중 오류 알림이 뜨지 않게 한다. Paper 뒤의 숨겨진 Rebuttal은 저장된 한국어 선택 때문에 번역 작업을 시작하지 않는다. 실제 답변 화면을 열면 필요한 갱신을 시작한다. 이미 진행 중인 번역과 수동 한국어 초안 보호는 유지한다.

기능 브라우저 검사 5개와 기존 번역·읽기 위치 검사 3개가 통과했다. 운영 이미지 기반 후보에서도 관련 검사 5개를 확인했다. 한영 각각의 저장, 혼합 선택, 논문 간 분리, 전체 Paper 페이지 새로고침, 숨겨진 화면의 번역 억제, 잘못된 값·저장소 거부, 기존 한국어 갱신과 원문·OpenReview 위치 유지를 확인했다.
