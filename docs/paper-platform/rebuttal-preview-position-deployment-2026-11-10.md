# 영문 OpenReview 미리보기 위치 복원 · 2026-11-10

영문 답변에서 OpenReview 미리보기를 끄면 보던 구절이 편집기의 같은 화면 높이에 나타나고, 해당 위치에 커서와 입력 포커스를 둔다. 편집기에서 미리보기를 켤 때도 보던 구절을 따라간다.

## 변경

- 영문 답변 미리보기에 Markdown 원문의 위치 정보를 붙이고, 화면에 보이는 텍스트의 위치를 편집기 위치로 변환한다. 긴 문단 내부, 반복 구절, 목록·표·코드 주변도 구분한다.
- 실제 보기 전환에서만 위치를 복원한다. 예약된 복원 전에 문서·언어·본문이 바뀌면 이전 위치를 적용하지 않는다.
- 전환은 원문을 수정하지 않는다. CRLF 원문은 공유 문서에 그대로 보존하고, 편집기의 LF 위치를 기준으로 이동한다.
- 모바일 미리보기와 편집기의 높이를 맞춰 본문 내부에서 스크롤하며 페이지 위치를 유지한다.

## 검증

새 Playwright 회귀 7개가 통과했다. 실제 협업 문서와 화면 좌표로 긴 문서, 한 문단 안의 단어, 목록·표·코드·수식 주변, 반복 구절, 양방향 반복 전환, CRLF 보존, 모바일 스크롤과 즉시 입력을 확인했다.

기존 미리보기·수식·한국어 연결·커서 호환 검사 6개 중 5개가 첫 실행에 통과했다. 좁은 편집창의 접속자 이름표 검사 1개는 첫 실행에서 실패했으며, 추가 비교에서 배포 전 번들과 수정 번들 모두 동일 검사를 통과했다. 이번 변경에 따른 회귀는 재현되지 않았다.
