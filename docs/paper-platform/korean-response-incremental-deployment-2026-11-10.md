# 한국어 번역 점진 처리 · 2026-11-10

한국어 번역에 한정하여 속도와 표시 안정성을 개선하고 운영에 반영했다. 기존 영어 답변, 수동 한국어 내용, 다른 분석의 모델 설정은 유지한다.

- 번역 전용 `rebuttal-translation-light` 프로필: GPT-6.1 Terra, `model_reasoning_effort="low"`. 기존 번역 프로필의 Medium 설정과 분리했다. 실행 환경의 모델 목록에서 Low 지원을 확인하고 실제 호출을 검증했다. 설정 키는 [공식 구성 문서](https://learn.chatgpt.com/docs/config-file/config-reference#model_reasoning_effort)를 참고한다.
- 번역 전용 작업자를 추가해 연결·문체 분석 작업이 번역을 가로막지 않도록 했다. 프로젝트별 순환 순서와 동일 입력 진행 작업의 중복 제출 방지를 적용했다.
- 문단별 번역을 프로젝트 안에서 재사용한다. 원문·용어집·프로필·엔진 버전으로 캐시를 구분하고 변경한 문단만 새로 호출한다. 문단 삽입·삭제·이동과 반복 문단을 보존하며, 성공한 문단은 나머지 작업이 실패해도 다음 요청에서 재사용한다.
- 모델은 번역문만 반환한다. 문장 대응표를 중복 생성하는 작업을 제거하고 서버가 원문 블록과 번역 블록을 연결한다. 한국어·길이·코드·수식 보존을 검증하고 실패한 블록만 한 차례 추가 시도한다.
- 개별 작업 조회 API로 완료한 문단부터 표시한다. 부분 결과는 화면에서만 보여주고 검증된 완료 결과를 공유 텍스트에 저장한다. 영문이 도중에 변경되면 최신 내용으로 후속 번역한다.
- 번역 상태 변화와 언어 탭 전환은 화면 전체를 다시 만들지 않는다. 동일한 내용·연결은 DOM을 유지해 선택·스크롤·미리보기의 불필요한 재구성을 줄인다.
- 실패나 수동 한국어 교체 취소 이후 같은 입력을 자동 반복하지 않는다. 여러 탭의 결과 경합과 수동 수정 보존을 검증했다. 용어집 변경도 재번역 조건에 포함한다.

## 검증

서버·브리지 검사 82개, 새 번역 엔진 검사 33개, 브라우저 검사 7개를 확인했다. 서버 검사 81개 통과 후 ETag 보완에 영향을 받는 4개 검사를 실행했고, 새 ETag 검사까지 통과했다. 브라우저는 최초 6개를 통과한 후 용어집 변경 관련 1개만 추가 검증했다.

실제 인증을 사용하는 별도 컨테이너에서 두 문단 예제를 실행했다. 첫 부분 표시 4.44초, 전체 9.47초(모델 호출 2회), 한 문단 수정 5.40초(1회), 동일 입력 재사용은 모델 호출 0회였다. 짧은 격리 예제 측정이며 기존 운영 기록과 동일 입력 비교는 아니다. 한 문단 안에 안전한 분할 경계가 없고 8,000자를 넘으면 내용을 훼손하지 않도록 오류를 반환한다.
