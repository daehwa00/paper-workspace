# Hub alignment · 2026-11-11

프로젝트 메인 화면의 상단 제목과 목록 제목 시작점, 검색·정렬 도구와 메타데이터 열을 같은 여백·열 너비로 맞췄다. 넓은 화면에서 제목 시작점의 기존 16px 차이를 제거했다. 행과 로딩 표시도 동일한 열 너비 변수를 사용한다.

목록 자체의 너비가 600px 이하이면 검색·정렬 도구를 제목 다음 줄에 배치하고, 520px 이하이면 행 메타데이터를 제목 아래에 배치한다. 저장된 사이드바가 넓은 작은 데스크톱 화면에서 페이지 수가 프레임 바깥으로 잘리던 경우를 포함한다. 작은 화면의 썸네일은 제목 첫 줄에 맞춘다.

검증:

- 기존 목록·다국어·검색·정렬 검사 11개와 메타데이터 편집·실행 취소·반응형 검사 3개 통과.
- Chromium·Firefox·WebKit에서 화면/사이드바 너비 조합 8개를 측정했다. 넓은 화면의 제목·도구·열 시작점 차이는 0px이고, 320~2155px 범위에서 행의 정보가 프레임 안에 유지된다. Chromium의 밝은/어두운 테마도 확인했다.
- 최신 운영 이미지를 기준으로 `hub.css`와 `hub.html` 캐시 버전만 교체했다. 이미지에서 추출한 파일로 관련 기존 검사 7개와 같은 너비 조합의 좌표 검사를 확인했다.
- 이미지와 실행 중인 파일 68개의 SHA-256, 내부 HTTP 응답, 서비스 상태는 비공개 릴리스의 `verification.json`에 기록한다. 다른 서비스의 컨테이너와 이미지는 교체하지 않는다.
- 운영 계정으로 로그인한 상호작용은 검사하지 않았다. 브라우저 검사는 배포 파일과 격리된 합성 데이터로 수행했다. HTTPS 인증서와 비로그인 401 응답은 로컬 Caddy로 도메인을 지정하여 확인한다.
