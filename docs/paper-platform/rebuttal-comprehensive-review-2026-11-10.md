# 리버탈 전체 점검 · 2026-11-10

최근 번역·접속자 수정 이후 리버탈 작성, 저장, 협업, 메모, 분석, 제출과 복원 경계를 점검했다. 독립 코드 검토와 설계 검토, 운영 정적 파일 조합의 브라우저 회귀 검증을 함께 수행했다.

## 발견 및 수정

1. **초기 동기화 전 빈 본문 내보내기·고정·백업**: 메타데이터 화면이 먼저 활성화될 때 공유 본문 대신 `seed_text`를 사용했다. 작업 경계에서 초기 준비와 실제 공유 텍스트를 확인한다. 실제로 빈 `Y.Text`는 정상 본문으로 보존한다. 출처가 없는 읽기전용 초기 본문은 화면에 표시할 수 있지만 제출·백업의 본문으로 쓰지 않는다.
2. **재분석이 저자의 확정·거절 결정을 숨김**: AI 출처라는 이유만으로 모든 이전 연결을 대체했다. 미확정 제안만 대체하고 저자가 결정한 연결과 우려는 보존한다. 해당 범위의 재분석에서는 과거에 잘못 숨겨진 결정도 복구한다.
3. **한국어 백업 복원의 초기화 경합**: 새 라운드가 공개된 뒤 다른 탭이 빈 한국어를 먼저 만들 수 있었다. 복원 트랜잭션에서 불변 `korean_seed:{text,meta}`를 새 문서와 함께 공개한다. 모든 최신 탭이 같은 초기값을 사용하며, 영어·한국어를 한 번에 초기화한다. 기존 공유 값은 빈 값이어도 덮어쓰지 않는다. seed는 복원 출처이며 내보내기의 대체 본문이 아니다.
4. **변경 전 한국어의 정상 내보내기**: 선택한 문서와 포함되는 공통 답변의 실제 영문·용어집을 번역 기록과 비교한다. 오래된 기계번역은 재번역을 요구하고, 출처 없는 수동 초안은 명시적으로 검토 확인을 받는다. 용어집 기록이 없는 예전 번역도 한국어 탭에서 재번역할 수 있다. 확인 중 한국어가 바뀌면 다시 검토해야 한다.
5. **제출 확인 중 보이지 않은 문서·규정 포함**: 확인창을 열 때 라운드, 문서 ID·순서, 본문과 활성 규정을 캡처하고 저장 전에 비교한다. 공통 답변도 구체적인 ID로 확정해 서버가 새로운 공통 답변을 추가로 포함하지 않는다. 전체 분량 규정이 있으면 검증에는 전체 문서 본문을 사용하되 출력은 선택한 문서로 유지한다.
6. **불확실한 연결이 기존 결과를 대체**: 단문 수리 후 문맥 관계로만 남긴 결과도 부분 완료 경고를 유지한다. 캐시 재사용 때도 경고·진단을 복사한다. 이전 처리 방식의 캐시는 직접 연결 처리 버전 `v10`으로 분리했다. 인용 검증과 저자 결정은 완화하지 않는다.
7. **모바일 답변 탐색 불가**: 767px 이하에서 숨겨진 리뷰어·공통 답변 탐색을 복구한다. 모바일 캐릭터 버튼의 실제 터치 영역도 44px로 유지한다. 긴 라벨·고대비 모드의 클릭 겹침을 검증한다.

- 첫 전체 브라우저 회귀: 기존 두 접속자 검사의 유효한 선행 근거를 재사용하고 나머지 118개를 한 번 실행했다. 112개 통과, 모바일 탐색 관련 6개 실패를 재현했다. 편집·저장·협업·409 충돌, 버전 복원, 메모 동시 편집·오프라인 대안 보존, Markdown·수식 미리보기는 통과했다. 후속 10개 중 문서 전환·뷰어·정상 내보내기 6개가 통과했고, 남은 모바일 4개는 44px 터치 영역과 긴 라벨 클릭 겹침을 수정한 뒤 모두 통과했다. 고대비 모드의 포인터 전환까지 확인했다.
- 백엔드의 분석·가져오기·통합·리뷰 구조 검사 118개와 협업의 소스·초기화·백업·연결 위치 관련 Node 검사 38개가 통과했다.

성공한 검사는 변경 영향이나 새 실패 근거가 있을 때만 해당 범위를 다시 실행했다. 실제 모델 호출과 학회 제출·배포 외부 공개는 이 검증에 포함하지 않았다.

## 독립 검토

코드 검토는 최초 두 HIGH와 새 총량 규정 회귀를 수정한 뒤 `APPROVE`, 설계 검토는 네 경계 결함과 같은 총량 회귀를 수정한 뒤 `CLEAR`를 확인했다. 최종 판정은 검토 범위 내 확정된 미해결 차단 사유가 없다는 뜻이며, 모든 가능한 오류의 부재를 보장하지 않는다.
