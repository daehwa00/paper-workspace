# 답변 한국어 번역 · 2026-11-07

운영 릴리스: `20261107-simple-korean`

답변 영역의 English/한국어 전환에서 영문 답변의 한국어 번역을 볼 수 있다. 아직 번역이 없고 영문이 있으면 한국어 탭을 열 때 번역한다. 영문이 바뀌면 한국어 화면에 변경 사실과 다시 번역하는 버튼을 표시한다. 기존 한국어가 번역 이후 직접 수정된 내용이면 교체 전 비교한다. 번역은 영문과 별도 공유 텍스트에 저장하므로 영문과 기존 리뷰 연결을 바꾸지 않는다. 한국어 번역은 JSON 백업·새 라운드 복원에도 포함된다.

제출 내보내기에서 English 또는 한국어를 선택할 수 있다. 한국어는 텍스트와 Markdown 내보내기를 지원하며, PDF·템플릿 소스는 기존 렌더러의 한국어 지원을 확인하지 못해 제한한다. 한국어 번역은 원문이 바뀌면 자동으로 새 내용이라고 가정하지 않는다.

기존 운영 이미지를 바탕으로 화면과 Rebuttal 서버만 변경했다. 실제 모델을 포함한 별도 인증·협업·저장소 환경에서 한국어 자동 번역, 전환, 새로고침 후 보존을 확인했다. 앞선 격리 검증에서 번역 내용 비교, 한국어 텍스트 내보내기, JSON 백업과 새 라운드 복원을 확인했으며, 사용자 요청에 따라 별도 한국어 편집기와 연결 목록은 제거했다. Python 관련 검사 97개, 번역·메모 관련 브라우저 검사 18개, 단순화 후 브라우저 검사 3개, 백업 검사 6개가 통과했다. 정적 자산 60개 참조 해시도 확인했다.
