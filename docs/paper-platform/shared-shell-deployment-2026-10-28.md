# Paper·Rebuttal 공통 요소 추가 정리 · 2026-10-28

릴리스: `20261028-142009-shared-shell`

이전 버튼·메뉴·설정창 통합 이후 남아 있던 공통 UI의 차이를 점검했다.
같은 역할의 요소는 기존 공통 계층으로 합쳤으며, 원고·PDF·리뷰·답변의
내용 구성은 각 화면에 유지했다.

## 확인한 차이와 조치

| 요소 | 남아 있던 차이 | 공통 구현 |
| --- | --- | --- |
| 사이드바 접기 | SVG와 별도 문자·마스크 아이콘, 다른 hover 및 이름 | `PaperUI.updateSidebarToggle`, `.sidebar-toggle` |
| 문서 패널 제목줄 | 44/48px 높이, 좌우 여백·글자 크기 차이 | `theme.css`의 `.panel-header`: 데스크톱 최소 48px, 터치 최소 52px, 동일 폰트·여백 |
| 패널 조절 막대 | 6/10px 폭, 손잡이와 hover·focus·drag 표현, 다른 키보드 동작 | `.workspace-resizer`, `PaperUI.bindResizer`: 문서 구분선 10px와 공통 조작 수명 주기 |
| 연결 상태 상세 | Paper의 상태 팝업과 Rebuttal의 업무용 모달 | `PaperSidebarAccount.createStatusPanel`: 공통 팝업·닫기·포커스·위치 처리 |
| 답변 안 접속자 | 별도 이니셜 계산, 5px 겹침, 모바일 44px 원 | 응답 범위를 지정한 `PaperProjectPresence`: 28px 원·4px 겹침·44px 터치 영역 |
| 모바일 계정 영역 | Paper의 구형 `project-name` 규칙으로 접속자 위치가 3px 다름 | 사용하지 않는 클래스·규칙 제거, 공통 프레임 규칙 사용 |

더 이상 생성되지 않는 보조 도구 버튼의 CSS와 중복 리사이저·상태창
규칙도 제거했다. 스타일시트는 작업 전보다 205줄 줄었다.

패널의 동작 범위·단위와 저장은 각 화면의 기존 설정을 사용한다.
Home/End는 현재 조절 막대의 최소·최대로 이동한다. 전체 배치 초기화는
기존 초기화 버튼으로 수행하며, 다른 사이드바·도우미·확대 설정은 유지한다.

상태 내용은 화면의 실제 상태를 유지한다. Paper는 공동 편집·저장·PDF·백업과
복구 동작을, Rebuttal은 현재 답변 파일·충돌 보존 경로를 보여 준다.
팝업을 연 상태에서 내용이 길어지면 화면 안으로 위치를 다시 맞춘다.

접속자 팝업은 잘리는 패널 위에도 표시된다. 키보드로 첫 사용자에 진입하고
Escape로 돌아올 수 있으며, 포커스에 따른 스크롤이나 화면 갱신이 발생해도
현재 목록과 포커스를 유지한다. 답변 접속자는 현재 답변 사용자만 표시하고,
본인의 다른 탭도 제외하며, 선택한 사용자의 답변 위치로 이동한다.

일시적인 Paper 알림과 지속적인 Rebuttal 안내는 목적이 다르므로 위치와
표시 기간을 유지했다. PDF 전용 도구, 리뷰 연결 표시, 업무용 폼의 구성도
공통화 대상으로 취급하지 않았다.

## 검증

- 브라우저 검사 56개: 새 공통 요소 검사 6개, 관련 기존 동작 및 회귀 검사.
- Python 계약·배포 검사 107개. 조절 막대·사이드바·상태창의 소유 위치를
  확인하는 검사는 공통 구현에 맞춰 수정했다.
- 실제 운영 파일을 바탕으로 한 배포 후보 13개 시나리오. 이후 수정된
  상태창의 크기 변경, 접속자 키보드·스크롤·갱신 동작은 해당 범위에서 재확인했다.
- CSS 파싱·변환과 JavaScript 구문, 변경 범위의 공백 검사를 통과했다.
- 운영 HTTPS의 320·390·1600px × 한국어·영어 × 밝음·어두움 12개 조건에서
  제목줄·상태창 스타일, 접속자 크기·간격·터치 영역, 팝업의 화면 내 위치를 확인했다.
  사이드바 양방향 동기화, 조절 막대, 키보드 포커스 및 실제 답변 선택 위치로
  이동하기도 통과했다. 최종 검증 브라우저 오류는 없었다.
- 초기 답변 5개 중 4개는 해시가 같았다. 나머지 1개는 첫 배포 전인 14:25부터
  별도 편집 이력이 쌓였으며, 최신 내용은 서버 파일·브라우저·저장 버전이 일치했다.
  초기 버전도 보존돼 있다. 변경 중인 답변을 이전 검증 기준으로 되돌리지 않았다.
- 검증 과정의 본문 수정·라운드 생성·LLM 요청은 0건이다. 최종 배포 파일
  15개를 확인했고, 운영 서비스 10개는 모두 healthy다.
