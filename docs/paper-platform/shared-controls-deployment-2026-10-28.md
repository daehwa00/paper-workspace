# Paper·Rebuttal 공통 버튼·메뉴·설정창 · 2026-10-28

운영에 `20261028-133511-shared-controls` 릴리스를 반영했다.
Paper, 내장 Rebuttal, 단독 Rebuttal이 같은 버튼·메뉴 스타일과
프로필·화면 설정 컨트롤러를 사용한다.

## 변경

- `sidebar-account.js`: 공통 마크업을 읽기 쉬운 템플릿으로 정리하고,
  프로필 이름 검증·저장·색상·협업 사용자 갱신·탭 간 동기화를 공통화했다.
  Paper의 최초 이름 입력 요구는 유지한다.
- `theme.js`: Rebuttal에도 같은 테마 설정 구현을 연결했다. 중복된
  테마 적용·번역·이벤트 코드를 제거했다.
- `bootstrap.js`: 설정·확인·입력창의 포커스 복원과 메뉴의 바깥 클릭,
  Escape, 방향키·Home·End 이동을 공통화했다. 숨김·비활성 항목은 건너뛴다.
- `theme.css`: 버튼, 계정 컨트롤, 모바일 메뉴, 설정창과 작업 메뉴의
  크기·폰트·간격·상태 스타일을 소유한다. 파일 메뉴와 Rebuttal 고급 메뉴가
  같은 `action-menu`를 사용한다. 터치 영역은 44px, 기본 데스크톱 컨트롤은 28px다.
- `project-frame.css`는 위치·반응형 배치를 담당한다. Rebuttal 고유 폼 규칙은
  `#form-dialog`로 한정하여 공통 설정창에 영향을 주지 않도록 했다.
- 6개 스타일시트에서 관련 중복과 구형 예외를 정리했다. 작업 전 대비
  CSS가 379줄 감소했다. 화면별 상태 상세와 업무용 폼 내용은 각 화면이 소유한다.
