# 전역 검토 후 수정과 배포 · 2026-10-28

운영 릴리스: `20261028-161110-global-integrated`

전역 검토에서 확인한 6개 오류와 검사 계약 불일치를 수정했다.

- Rebuttal 재렌더링에서 포커스 대상이 없을 때 발생하던 예외를 제거했다.
- 늦게 도착한 조회 응답이 최신 revision이나 작업 상태를 되돌리지 않도록 했다.
- 패널 조절 키 입력을 실제 모델 값에 누적하고, 드래그는 화면의 실제 시작 위치를 사용한다.
- 단독 Rebuttal과 Paper의 같은 브라우저 탭이 사용자 ID를 공유한다.
- 내장 Rebuttal의 라운드가 상위 공유 주소·이력·새로고침과 동기화된다.
- 미치환 자산 토큰과 검사 오류가 있으면 Docker 이미지 빌드가 실패한다.

추가 독립 리뷰에서 발견한 빠른 뒤로가기·화면 전환 경합도 수정했다. 느린
초기화가 끝나더라도 사용자의 더 최근 화면 선택을 덮어쓰지 않는다. 실제
인증·WebSocket·Rebuttal API와 저장소 재시작을 검증하는 CI 검사를 추가했다.

기존 회귀 검사 5건의 오래된 기대값을 현재 접근성·편집기·서버 계약에 맞췄다.
별도 작업에서 운영에 반영된 메모 패널과 내장 화면의 메모 저장 수정도 유지했다.

## 검증과 배포

- 전체 브라우저 검사 431건의 통과 근거를 확보했다. 최초 실행에서 실패한
  두 검사는 표시와 전환 완료 전 좌표를 읽는 문제를 바로잡아 재확인했다.
- 새 비동기 탐색 회귀 3건과 통합 메모 검사 5건도 통과했다. 최종 이미지
  파일 조합으로 전체 수정 회귀 11건과 내장 메모 저장을 다시 확인했다.
- Python 검사 443건과 릴리스 설정 검사 26건, 협업 서버 검사 71건이 통과했다.
- 합성 계정과 임시 데이터만 사용하는 실제 Docker 인증·WebSocket·Rebuttal·
  LevelDB·SQLite 재시작 검사가 통과했다. 임시 컨테이너와 볼륨은 정리됐다.
- 운영 HTTPS에서 인증, Paper·Rebuttal 화면, 메모 패널, 상태 조회를 확인했다.

Compose 파일로 고정했다. 화면 서비스만 교체했으며 나머지 백엔드 이미지와
마운트는 유지했다. 병행 작업의 메모 기능을 포함했고, 작업 폴더의 다른
